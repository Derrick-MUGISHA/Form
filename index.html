How it is built

Three decisions shape the whole project. The documentation walks through each of them in detail.

  1. One layout, reused everywhere A single CSS grid with six named areas side, nav, main, hist, prof and user is declared once in the stylesheet. Every page fills the same slots, so navigating never moves the furniture around you.
  2. One stylesheet, in fourteen sections css/styles.css holds design tokens, the shell, each panel, the form, the lesson demos, the breakpoints and a print rule. Lesson demos are scoped to their own class so an experiment can never leak into the layout.
  3. Responsive by reflow, not by hiding At 1180px the history panel moves below the main column; at 860px everything becomes one column and the sidebar turns into a scrollable strip of pills. Nothing is hidden on small screens it is only rearranged.
